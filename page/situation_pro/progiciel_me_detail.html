Progiciel ME

Le Progiciel ME est un progiciel de gestion dédié aux maisons d'édition. Passionné par ce milieu, j'ai développé cet outil en HTML, CSS et PHP, avec une API PHP/JSON pour optimiser les performances.

Fonctionnalités

Le progiciel permet de gérer l'ensemble des ressources d'une maison d'édition :

Livres

Auteurs

Licences

Genres

Imprimeurs

Conventions

Maisons d'édition

Schéma de base de données

Mentions légales Politique de confidentialité
